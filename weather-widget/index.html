홈 화면에 위젯 추가하기

iPhone

  1. 보는날씨 앱을 설치하고 한 번 열어 날씨를 확인하세요.
  2. 홈 화면의 빈 곳을 길게 누르고 위젯 추가 메뉴를 여세요. iOS 버전에 따라 ‘편집 → 위젯 추가’ 또는 + 버튼으로 표시됩니다.
  3. ‘보는날씨’를 검색해 원하는 크기를 추가하세요.

갤럭시·Android

  1. 보는날씨 앱을 설치하고 한 번 열어 날씨를 확인하세요.
  2. 홈 화면 빈 곳을 길게 누른 뒤 ‘위젯’을 선택하세요.
  3. ‘보는날씨’를 찾아 홈 화면으로 추가하세요. 메뉴 이름은 기기와 런처에 따라 다를 수 있어요.

어느 지역의 날씨를 볼까요?

앱의 전체 → 위젯 지역에서 이 기기의 위젯에 표시할 지역을 선택하세요.

모드어떻게 동작하나요?
현재 위치 따라가기허용된 위치를 확인해 해당 지역의 국내 날씨를 갱신해요.
홈에서 본 지역 따라가기앱 홈에서 확인한 지역을 위젯에 함께 표시해요.
한 장소 고정홈에서 다른 지역을 봐도 내가 선택한 장소를 유지해요.

현재 위치를 따라가게 하려면

  1. 앱에서 모드를 고르고 저장해요

    전체 → 위젯 지역에서 ‘현재 위치 따라가기’를 선택하고 안내에 따라 저장하세요.

  2. 기기의 위치 권한을 확인해요

    iPhone은 설정 → 개인정보 보호 및 보안 → 위치 서비스 → 보는날씨에서 앱 또는 위젯의 위치 사용을 확인하세요. Galaxy는 설정 → 애플리케이션 → 보는날씨 → 권한 → 위치에서 앱을 닫아도 갱신하려는 경우 ‘항상 허용’을 확인하세요.

  3. 갱신 시각을 함께 확인해요

    배터리·통신·위치 수신과 운영체제의 실행 제한에 따라 갱신 시점이 달라요. 이전 날씨가 보이면 앱을 열어 지역과 날씨를 확인한 뒤 위젯의 새로고침을 이용해 보세요.

자주 묻는 질문

현재 위치 위젯이 해외에서도 자동 갱신되나요?

현재 위치를 이용한 자동 날씨 갱신은 국내 기준입니다. 해외 지역은 앱에서 확인한 날씨가 있을 때 표시하며 새 날씨를 자동으로 가져오지는 않습니다.

새로고침을 누르면 즉시 위치와 날씨가 바뀌나요?

항상 즉시 바뀌는 것은 아닙니다. 운영체제의 갱신 제한, 권한, 절전 상태와 통신 상황이 영향을 줍니다. 마지막 확인된 날씨를 유지할 수 있으므로 표시 시각을 함께 확인하세요.

지역명이 확인 중인데 날씨는 나오면요?

지역 이름 조회와 날씨 조회는 서로 다른 과정입니다. 앱과 위젯 지역 설정을 확인해 주세요. 계속되면 기종·앱 버전과 화면 상태를 고객 문의로 알려 주세요.

다른 위젯마다 다른 장소를 지정할 수 있나요?

현재 이 기기에 추가한 보는날씨 위젯들은 같은 지역 설정을 사용합니다.
